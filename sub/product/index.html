취약점진단 자동화 플랫폼

정보통신기반시설 및 클라우드 시스템 취약점진단 자동화 를 제공합니다.

01
Zero Trust Vulnerability Management

통합 취약점 진단, Zero Trust로 설계했습니다

BingoCVM은 시스템·소프트웨어·네트워크 취약점을 하나의 플랫폼에서 진단하는 제로트러스트 기반 통합 취약점관리 솔루션입니다.

“

취약점이 존재하는 시스템은,
신뢰하지 않는다.

모든 자산의 신뢰는 진단으로 증명됩니다 — BingoCVM은 그 증명을 자동화합니다.

도입효과
  • 제로트러스트 기반 통합 취약점 관리
    (시스템취약, 소프트웨어취약, 네트워크스캔취약, 위협인텔리전스)
  • 국내 컴플라이언스 규정준수 — ISMS-P, CSAP, ISO27001 인증 획득 및 준수 관리
  • 공공기관 사이버보안 실태평가 대응
지원 플랫폼
  • 온프레미스부터 클라우드까지, 하나의 플랫폼으로 통합 지원
  • 진단 대상 — Unix/Linux 서버, Windows 서버, PC, 웹, DBMS, Network, 가상화, 클라우드 플랫폼
핵심 기능
시스템 취약점 자동 진단 실시간·스케줄 진단으로 담당자의 업무시간을 단축합니다
소프트웨어 패치 관리 기준 CVE 진단으로 해킹·랜섬웨어를 사전에 방지합니다
네트워크 스캔 진단 공격 표면의 취약점을 탐지하고 패치 기준을 제공합니다
Agent + Non-Agent 적용 즉시 실시간 진단과 스케줄 진단을 모두 지원합니다
온프레미스 + 클라우드 통합 하나의 플랫폼으로 도입 비용과 운영 부담을 줄입니다
통합 보고서 자동 생성 자산·그룹별, 월별, 날짜별 비교 보고서를 제공합니다
관리적·물리적 취약점 보고서 정보보호관리체계 인증에 필요한 보고서까지 제공합니다
자산 중요도 기반 복구 관리 상/중/하 등급과 RTO·RPO·복구 우선순위를 관리합니다
02
Advanced Intelligence Architecture

탐지에서 대응까지, 지능형 아키텍처로 완성합니다

BingoCVM은 취약점을 탐지하는 데 그치지 않고, 위협 인텔리전스와 자산 중요도 기반 복구 전략까지 하나의 흐름으로 연결합니다.

통합 탐지 엔진

Integrated Detection Engines

  • CCE시스템설정취약점 · 운영 시스템 및 인프라의 보호 설정 오류나 컴플라이언스 위반 사항을 정밀 분석하고 진단합니다.
  • CVE소프트웨어취약점 · 서버, 운영체제, 애플리케이션 및 오픈소스 등 알려진 시스템의 다양한 소프트웨어 취약점을 탐지합니다.
  • NSE네트워크스캔취약점 · 고성능 네트워크 스캐닝 엔진으로 실시간 대역별 취약 자산을 스캔하고 잠재적 위험을 탐지합니다.

위협 인텔리전스 지표 Ai

Threat Intelligence Indicators

  • CVSS소프트웨어취약점 스코어 · 취약점의 기술적 심각도를 정량화한 글로벌 표준 점수 체계로 객관적인 위험도 파악이 가능합니다.
  • EPSSAI예측분석취약점 스코어 · 실제 공격에 이용될 확률을 예측하는 AI 기반 분석 모델로 데이터 기반의 의사결정을 지원합니다.
  • KEV실제공격에사용된취약점 · 야생(In-the-Wild)에서 활발히 악용 중인 위협·해킹 사례를 연동해 실제 악용 여부와 최우선 대응 지표를 제공합니다.

자산의 중요도 기반 복구관리

Asset Criticality-Based Recovery Management

자산 중요도 관리 (상, 중, 하) — 모든 자산을 동일한 수준으로 복구하지 않습니다. 중요도(Criticality)를 평가해 제한된 인력과 자원을 가장 중요한 자산에 먼저 투입하는 복구 전략입니다.
자산 복구 관리 (RTO, RPO, 복구우선순위) — RTO, RPO, 복구 우선순위는 재해복구(DR)와 업무연속성계획(BCP)의 핵심 요소이며, BingoCVM에서 자산별로 관리할 수 있습니다.

04
취약점 진단 프로세스

5단계 체계적 취약점 진단 프로세스

BingoCVM의 취약점 진단 프로세스는 체계적이고 단계적인 접근으로 빠짐없는 취약점관리를 실현합니다.
취약점 진단 주요단계는 자산등록, 취약점진단, 취약점분석, 취약점조치, 이행점검으로 이루어집니다.

01
자산등록
  • 모든 IT 자산을 Agent 또는 Non‑Agent 방식으로 식별하여 등록
02
취약점 진단
  • CCE 진단 스크립트를 자동으로 배포·실행하고 결과 파일을 수집
  • CVE 기반 자산 자동 매핑으로 스캔 결과를 통합 수집 (2026년 적용)
자동화
03
취약점 분석
  • 수집된 CCE 시스템취약점진단 결과를 분석하여 항목을 취약 / 양호 / 예외로 분류
  • CVE 소프트웨어 취약점 기반 AI 분석을 통해 취약점에 대한 정밀 분석 수행 (2026년 적용)
AI 분석
04
취약점 조치
  • 발견된 취약점에 대해 수동 또는 자동으로 조치 수행
  • 조치 이력과 증적 자료를 체계적으로 저장
05
이행 점검
  • 조치 완료 후 재진단을 수행하여 이행 여부를 검증
  • 최종 진단 보고서 및 비교 보고서 제공 (다운로드 가능)
05
취약점 유형 소개

CCE 시스템취약점과 CVE 소프트웨어취약점

BingoCVM은 CCE(시스템 취약점)와 CVE(소프트웨어 취약점) 두 가지 유형을 통합 진단합니다.
설정 오류부터 알려진 버그까지, 하나의 플랫폼에서 모두 관리합니다.

Common Configuration Enumeration
CCE 시스템취약 개요
시스템과 소프트웨어의 보안 설정 오류(Configuration Weakness)를 표준 식별번호로 관리하는 체계입니다.
KISA의 취약점 표준 체계
대한민국에서는 한국인터넷진흥원(KISA)이 주요 정보보호 취약점 기준을 관리·보급합니다. 다음과 같은 국내 표준 취약점 점검 기준을 제공합니다.
① 주요정보통신기반시설 기술적 취약점 분석·평가 기준
  • 전자정부, 공공기관 대상
  • 서버/네트워크/DB/보안장비 점검 항목 제공
  • 항목 구조는 CCE 개념과 유사 (설정 기반 점검)
② 국가 정보보안 기본지침 / 전자정부 보안 가이드
  • 계정관리
  • 접근통제
  • 로그관리
  • 암호정책
Common Vulnerabilities and Exposures
CVE 소프트웨어취약 개요
소프트웨어나 하드웨어 제품에 존재하는 보안 취약점(버그)에 부여되는 고유 식별번호입니다.
CVE 취약점의 주요 내용
  • CVE 의미: 소프트웨어 결함
  • CVE 대상: 소프트웨어 제품 코드 취약점
  • CVE 약점: 해커가 직접 공격 가능
  • CVE 해결: 소프트웨어 취약점 점검 및 패치
CVE의 특징
  • 실제 공격 가능한 코드 취약점
  • 형식: CVE-연도-번호
    예: CVE-2024-12345
  • CVSS 점수와 연계 (위험도 평가)
CVE 예시
CVE-2021-44228
Apache Log4j의 Log4Shell 원격 코드 실행 취약점
CVE-2017-0144
Microsoft Windows SMB 취약점 (WannaCry 악용)

지원 플랫폼

BingoCVM은 KISA 취약점점검 가이드 기준으로 고객사의 다양한 시스템 환경에 맞춰 최적화된 진단 서비스를 제공합니다. 온프레미스부터 클라우드까지 폭넓은 지원 범위를 자랑합니다.

OS & 가상화
  • Windows Server: 2003 R2, 2008 ~ 2022
  • Windows PC: 7, 8, 10, 11, Mac PC
  • Linux: RHEL, CentOS, Ubuntu, Rocky, Debian, Amazon Linux 등
  • Unix: HP-UX(11+), AIX(5.2+), Solaris(5.8+)
  • Virtualization: ESXi, Hyper-V, KVM, Docker, Kubernetes(Master/Worker)
DBMS & Cloud
  • RDBMS: Oracle, MySQL, MSSQL, MariaDB, PostgreSQL, Tibero, Cubrid
  • NoSQL: MongoDB, Redis, Elasticsearch
  • Cloud Platform: AWS, Azure, GCP, KT Cloud, Naver Cloud 등
  • Cloud Infra: VM, Container, K8S, Cloud DB, OpenStack, Hadoop
WEB/WAS & Network
  • WEB: Apache, IIS, Nginx, WebtoB
  • WAS: Tomcat, Jeus, WebSphere, WebLogic, JBoss
  • Network: Cisco, Juniper, Alteon 등 스위치/라우터
  • Security Device: Firewall, IPS, VPN, DDoS (매뉴얼 진단 지원)
