CONTINUOUS SECURITY VERIFICATION

통합 취약점 진단으로, Zero Trust를 실현합니다

BingoCVM은 시스템·소프트웨어·네트워크의 취약점을 통합 진단하고, 위협 인텔리전스와 자산 중요도를 기반으로 위험을 판단하여 대응 우선순위를 결정합니다.

“

신뢰는 기본값이 아니라,
지속적인 검증의 결과입니다.

자산을 지속적으로 검증하고, 검증된 데이터를 기반으로 위험에 맞는 대응을 결정합니다.

01
지능형 취약점 분석

탐지부터 위험 분석, 대응 우선순위까지 하나의 지능형 흐름으로 연결합니다

BingoCVM은 취약점을 탐지하는 데 그치지 않고, 위협 인텔리전스와 자산 중요도를 결합하여 위험을 판단하고 최적의 대응 우선순위를 도출합니다.

01

통합 취약점 탐지

Integrated Vulnerability Detection

CONFIGURATION 시스템 설정 취약점 CCE

운영 시스템 및 인프라의 보호 설정 오류와 컴플아이언스 위반 사항을 정밀 분석하고 진단합니다. (국내공공기관 기술적 취약점 점검 항목)

SOFTWARE 소프트웨어 취약점 CVE

서버, 운영체제, 애플리케이션 및 오픈소스 등 알려진 시스템의 다양한 소프트웨어 취약점을 탐지합니다.

NETWORK 네트워크 스캔 취약점 NSE Vulners

고성능 네트워크 스캐닝 엔진을 통해 실시간 대역별 취약 자산을 스캔하고 잠재적 위협을 탐지합니다.

02

위협 기반 위험 분석 Ai

Threat-Based Risk Analysis

SEVERITY 얼마나 심각한가? CVSS

취약점의 기술적 심각도를 정량화한 글로벌 표준 점수 체게를 제공하여 객관적인 위험도 파악이 가능합니다. Severity, Exploit, Impact Score

EXPLOITABILITY 얼마나 악용될 가능성이 높은가? EPSS

실제 취약점이 공격에 이용될 확률을 예측하는 AI 기반 분석 모델로 데이터 기반의 의사 결정을 지원합니다.

ACTIVE THREAT 실제로 공격에 사용되고 있는가? KEV

실제 야생(In-the-Wild)에서 활발하게 악용 중인 위협 및 해킹사례 취약점 목록을 연동하여 실제 악용 여부 확인 최우선 대응 지표를 제공합니다.

03

자산 중요도 기반 대응 전략

Asset-Criticality-Based Response

CRITICALITY 자산 중요도 상 · 중 · 하

모든 자산을 동일한 수준으로 복구하는 것이 아니라, 자산의 중요도(Criticality)를 평가하여 제한된 인력과 자원을 가장 중요한 자산에 먼저 투입하는 복구 전략입니다.

BUSINESS IMPACT RTO · RPO 업무 영향도

재해복구(DR)와 업무연속성계획(BCP)의 핵심 지표를 자산별로 관리합니다.

RECOVERY 복구 우선순위 Recovery Priority

위험도와 중요도를 결합해 가장 시급한 복구 대상을 결정합니다.

자산의 중요도와 업무 영향도를 반영하여 가장 중요한 자산부터 대응·복구 우선순위를 결정합니다.

RISK-BASED RESPONSE

"무엇을 먼저 보호해야 하는가?"를 결정합니다.

CRITICAL ASSET → HIGH RISK → IMMEDIATE RESPONSE
02
제로트러스트 아키텍처

발견하고, 검증하고, 평가하고, 판단합니다

BingoCVM은 자산을 발견하고 검증하며, 위험을 평가하고 대응 우선순위를 판단합니다. Zero Trust 원칙을 하나의 진단 엔진으로 연결해 보안 데이터를 실행 가능한 대응 우선순위로 전환합니다.

지속적인 보안 상태 검증

Agent · Agentless · Offline/Manual

자산의 보안 상태를 지속적으로 확인하고 환경에 맞는 다양한 방식으로 취약점을 진단합니다.

→
03 · EVALUATE

무엇이 실제로 위험한가?

위협 및 위험 분석

CVSS · EPSS · KEV

취약점의 기술적 심각도, 실제 악용 가능성, 공격 여부를 분석하고 자산의 중요도와 결합하여 실제 위험을 평가합니다.

→
RISK DECISION
04 · DECIDE

무엇부터 대응할 것인가?

위험 기반 대응 우선순위

Risk-Based Response

취약점 개수가 아니라 위험도와 자산 중요도를 기준으로 가장 먼저 대응해야 할 보안 과제를 결정합니다.

PRIORITY 01 · CRITICAL
ZERO TRUST → ACTION

무엇이 존재하는지 발견하고, 안전한지 검증하고, 무엇이 실제 위험인지 평가하여, 무엇부터 대응할지 결정합니다.

03
취약점 진단

설정부터 소프트웨어, 네트워크까지 하나의 진단으로

CCE · CVE · NSE Vulners 기반으로 다양한 취약점 신호를 통합 분석하고, Agent · Agentless · Offline 등 고객 환경에 맞는 방식으로 진단을 수행합니다.

01 · CONFIGURATION

시스템 설정 취약점

CCE

시스템과 인프라의 잘못된 설정을 탐지하여 구성 단계에서 발생하는 보안 위험을 식별합니다.

  • 보안 설정 기준 점검
  • 서버·네트워크 구성 진단
  • 보안 정책 준수 여부 확인
02 · SOFTWARE

소프트웨어 취약점

CVE

운영체제와 소프트웨어의 알려진 취약점을 식별하고 영향받는 자산과 패치 필요 여부를 분석합니다.

  • CVE 식별
  • 취약 버전 탐지
  • 패치 대상 분석
03 · NETWORK

네트워크 스캔 취약점

NSE Vulners

네트워크 서비스와 노출된 포트를 분석하여 외부에서 악용 가능한 취약점을 탐지합니다.

  • 서비스 탐지
  • 포트·프로토콜 분석
  • 네트워크 취약점 검증

지원 플랫폼

OS & 가상화
  • Windows Server: 2003 R2, 2008 ~ 2022

  • Linux: RHEL, CentOS, Ubuntu, Rocky, Debian, Amazon Linux 등

  • Virtualization: ESXi, Hyper-V, KVM, Docker, Kubernetes(Master/Worker)
DBMS & Cloud
  • RDBMS: Oracle, MySQL, MSSQL, MariaDB, PostgreSQL, Tibero, Cubrid
  • NoSQL: MongoDB, Redis, Elasticsearch

  • Cloud Infra: VM, Container, K8S, Cloud DB, OpenStack, Hadoop
WEB/WAS & Network
  • WEB: Apache, IIS, Nginx, WebtoB
