필요한 진단만 선택하고,
자산 규모에 맞춰 합리적으로 도입하세요.

BingoCVM은 자산 기반 CCE와 서버 기반 CVE/NET Vulners로 구성되어 비용 부담을 줄여줍니다.

라이선스 기준을 확인해보세요.

진단 항목 과금 기준 특징
CCE (시스템 설정 진단)
Device / Agent 수 OS·IP 자산 규모에 맞춰 가변 적용되는 자산 단위 라이선스
CVE (소프트웨어 취약점)
Manager Server 수 서버 1대 라이선스로 등록된 자산의 소프트웨어 취약점 진단
NET Vulners (네트워크 스캔)
Manager Server 수 서버 1대 라이선스로 네트워크 스캐닝 지원

CCE·CVE 기반 진단은 ISMS-P · K-RMF · CSAP 등 컴플라이언스 대응에 활용됩니다. 영구 라이선스와 연간 라이선스 중 선택할 수 있습니다.
