LICENSING OVERVIEW

라이선스 기준

진단 항목 라이선스 기준 핵심 특징
CCE (시스템 설정 진단)
Agent/Device 수 (자산 수 기준) 진단 대상 자산(OS/IP) 규모에 따른 라이선스
CVE (소프트웨어 취약점)
Manager Server 수 (등록된 자산 수 기준) Manager 기반 소프트웨어 취약점 진단
NET Vulners (네트워크 스캔)
Manager Server 수 (Manager 수 기준) Manager가 속한 네트워크 대역 스캔

CCE·CVE 기반 진단은 ISMS-P · K-RMF · CSAP 등 컴플라이언스 대응에 활용됩니다. 영구 라이선스와 연간 라이선스 중 선택할 수 있습니다.
