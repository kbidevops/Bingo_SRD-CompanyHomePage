PRODUCT · PRICE POLICY

진단 규모와 운영 환경에 맞춰
합리적인 라이선스를 선택하세요.

BingoCVM은 Manager Server 기반의 통합 진단 솔루션입니다. CCE는 Device/Agent(IP/OS) 수량을 기준으로, CVE·NSE Vulners는 Manager Server를 기준으로 라이선스가 적용됩니다.

영구 라이선스 | 연간 라이선스
  • Web · WAS · DB CCE 진단 자산 등록 후 기본 진단 기능으로 활용
  • CCE · CVE · NSE Vulners 진단 목적과 운영 환경에 맞춰 선택
  • 전문 보안 서비스 취약점 진단 및 모의해킹은 별도 서비스로 제공

CCE·CVE 기반 진단은 ISMS-P · K-RMF · CSAP 등 컴플라이언스 대응에 활용됩니다.

조달청을 통한 구매를 원하시나요?

BingoCVM은 조달청 디지털서비스몰에 등록된 제품입니다. 기존 계약을 통해 Manager Server 와 Device / Agent 를 편리하게 도입하세요.

BingoCVM 가격 상담

운영 환경과 진단 규모를 알려주시면 적합한 라이선스 구성을 안내해 드립니다.
